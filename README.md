# Jocuri C++

O colecție de jocuri simple realizate în C/C++, dezvoltate pentru a exersa programarea, logica și rezolvarea problemelor.

### Number Guesser

Un joc în care jucătorul trebuie să ghicească un număr ales de calculator.

### Rock Paper Scissors

O versiune în consolă a jocului **Rock Paper Scissors**, în care jucătorul concurează împotriva calculatorului.

## Tehnologii

* C++
* Aplicații de tip consolă
* Biblioteci standard C++
